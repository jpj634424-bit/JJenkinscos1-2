# Week 2 – Project Stand-Up

### What I Worked On

This week, I focused on expanding and improving my Console Fighter project. I worked on improving the combat system, including how attacking, defending, and damage calculations are handled. I also updated the game's menus to make them easier to understand and navigate. One of the biggest improvements was adding the ability to play another match or return to the main menu after a battle. I also improved the messages displayed during combat so players can better follow what is happening. Throughout the process, I tested the changes and committed my progress to GitHub.

###  Challenges I Encountered

One of my biggest challenges was making sure the new features worked correctly with the code I had already written. Since the project uses multiple classes, I had to pay attention to how everything connected. I also spent time working on input validation to make sure the program handled incorrect menu selections without causing problems. Testing the replay system and making sure fighter health and turn counts reset correctly were important parts of this process.

###  What I Learned or Improved

This week helped me improve my understanding of object-oriented programming and how different classes work together. I also gained more experience with debugging, testing, and organizing my code. I learned that even small improvements to a program's menus and messages can make a big difference in the overall user experience. Another important improvement was becoming more comfortable using GitHub to track changes and organize my development progress.

###  What I Plan to Focus On Next

For the next milestone, I want to continue expanding the fighting game by adding more features and making the combat system more interesting. Some of my planned improvements include adding special attacks that use energy, tracking wins and losses, and displaying more detailed fighter statistics. I also want to continue improving the game's menus and handling unexpected user inputs. My main goal is to keep building a more complete fighting game while strengthening my C++ programming skills.
